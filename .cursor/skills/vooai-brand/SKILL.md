# Marca VooAI

Fonte: `branding/vooai-brand-book.html`. Front só usa estes tokens.

```css
--voo-night: #0A1628;
--voo-amber: #E8A317;
--voo-sky: #3D7EA6;
--voo-paper: #F4F6F8;
--voo-ink: #1C2430;
--voo-muted: #6B7785;
--f-display: "Syne", sans-serif;
--f-body: "Manrope", sans-serif;
--f-mono: "IBM Plex Mono", monospace;
```

## Regras

- Wordmark **VooAI** + marca de trajetória (linha + nó). Sem avião cartoon.
- COMPRAR = âmbar; AGUARDAR = azul operacional; MONITORAR = chumbo.
- Proibido: roxo/indigo genérico, cream+terracota+serif, layout jornal, Inter/Roboto/Arial como display, glow, pills rounded-full como sistema.
- Hero: marca dominante; um headline; uma frase; um grupo de CTA; visual de pista/trajetória. Sem cards no hero. Sem overlays (badges flutuantes).
- Cards só para interação. Uma função por seção.
